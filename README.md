# Digital Banking Page Recreation (Nuxt 2 + Tailwind CSS)

Responsive, single-page visual recreation based on the supplied screenshots. This is a front-end template only; the sign-in form does not authenticate or submit credentials.

## Requirements
- Node.js 16 or 18 recommended for this Nuxt 2 project
- npm

## Run locally
```bash
npm install
npm run dev
```
Then open http://localhost:3000.

## Production build
```bash
npm run build
npm run start
```

The screenshot crops in `assets/images/` are included as local visual assets. Replace them with licensed/approved assets if publishing.
